# Changelog

## 1.1.0 — 2026-10-14

- Formalized the project as a portable Agent Skill named `experience`.
- Added `SKILL.md` with task routing, figure QA, bioinformatics reproducibility, interpretation, manuscript review, privacy, and update rules.
- Added installation and update instructions.
- Kept `Experience.md` as the expanded human-readable standard and `rules.yaml` as configurable defaults.
- Added the reusable population color palette to the machine-readable rules.
- Added an automated GitHub Actions workflow to package the skill as a downloadable ZIP whenever the source directory changes.
- Added an explicit versioning and maintenance workflow.
