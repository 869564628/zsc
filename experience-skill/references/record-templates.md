# Experience record templates

Use the smallest template that preserves useful information. Do not fill unknown fields with guesses.

## Deep Experience template

```markdown
# [Specific title]

**One-line value:** [What this helps someone do]
**Category:** [Subject / discipline]
**Tags:** [tag1, tag2, tag3]
**Difficulty:** [Optional; only if known]
**Estimated time:** [Optional; only if known]

## Context and scope
[Who this is for, prerequisites, where it applies, and limits.]

## Experience basis
[What was actually tried or observed. Separate personal experience from outside information.]

## Procedure / learning path
1. [Action] — [expected output or check]
2. [Action] — [expected output or check]
3. [Action] — [expected output or check]

## Resources
- [Resource name](URL) — [why it is useful]

## Pitfalls and recovery
- **Pitfall:** [What can go wrong]
  **Recovery:** [How to diagnose or fix it]

## Limits and open questions
[Uncertainty, exceptions, or details to verify.]

## Change notes
[Optional: what changed and why.]
```

## Vibe Experience template

```markdown
# [Memorable, searchable title]

**Type:** [Insight / analogy / method tip / warning / question / motivation]
**Category:** [Subject / discipline]
**Tags:** [tag1, tag2]
**Use case:** [When this thought is useful; optional]

[The insight in one to three short paragraphs.]

**Basis or caveat:** [Optional; add when needed to avoid overgeneralization.]
**Related Deep Experience:** [Link or title, if any]
```

## Quick classification

- If the content tells a reader what to do across several steps, use Deep Experience.
- If the content captures one useful idea, observation, analogy, or reminder, use Vibe Experience.
- If uncertain, start with Vibe Experience and promote it later when enough repeatable detail exists.
